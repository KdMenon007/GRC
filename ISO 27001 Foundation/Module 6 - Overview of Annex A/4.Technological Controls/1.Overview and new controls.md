
**A.8 Technological Controls** contains **34 controls** and focuses on protecting information and systems using **technical, automated, or logical security mechanisms**.

Examples include:

- Firewalls
    
- Encryption
    
- Antivirus/endpoint protection
    
- Access controls
    
- Network security
    
- Logging and monitoring
    
- Secure development
    
- Data protection
    

### The 7 new technological controls in ISO 27001:2022

|Control|Name|Main Purpose|
|---|---|---|
|**A.8.9**|Configuration Management|Maintain secure configurations and prevent unauthorized configuration changes|
|**A.8.10**|Information Deletion|Securely delete information when it is no longer required|
|**A.8.11**|Data Masking|Hide sensitive information to reduce exposure|
|**A.8.12**|Data Leakage Prevention|Prevent and detect unauthorized disclosure of information|
|**A.8.16**|Monitoring Activities|Monitor systems and identify unusual or suspicious activity|
|**A.8.23**|Web Filtering|Control web access and reduce exposure to malicious or inappropriate content|
|**A.8.28**|Secure Coding|Apply secure coding principles to reduce software vulnerabilities|

### A.8.9 — Configuration Management

Manage the **security configuration lifecycle** of technology.

This can include:

**Define → Implement → Monitor → Review**

Example:

> Maintain secure baseline configurations for servers and prevent unauthorized configuration changes.

---

### A.8.10 — Information Deletion

Information should be deleted when it is **no longer required**, considering security and legal/privacy requirements.

Examples:

- Deleting data from applications
    
- Securely deleting files
    
- Removing data from cloud services
    
- Securely disposing of removable media
    

**Goal:** Reduce the risk of unnecessary sensitive information being exposed.

---

### A.8.11 — Data Masking

Sensitive information is **hidden or partially obscured** so unauthorized users cannot see the actual values.

Example:

`Customer Card: 4532 7812 3456 9012`

becomes:

`Customer Card: XXXX XXXX XXXX 9012`

Commonly used for:

- Personal data
    
- Financial information
    
- Customer information
    
- Sensitive business information
    

---

### A.8.12 — Data Leakage Prevention

Organizations should implement measures to **prevent and detect unauthorized disclosure of information**.

Examples:

- DLP software
    
- Email content inspection
    
- Endpoint DLP
    
- Network DLP
    
- Blocking unauthorized USB transfers
    
- Monitoring sensitive file transfers
    

---

### A.8.16 — Monitoring Activities

Systems, networks, and applications should be monitored to identify **unusual or suspicious activity**.

Examples:

- SIEM monitoring
    
- Security logs
    
- Network monitoring
    
- Endpoint monitoring
    
- Authentication monitoring
    
- Alerting on suspicious behavior
    

For a SOC analyst, this is particularly important because monitoring helps detect potential incidents early.

**Flow:**

**Monitor → Detect abnormal activity → Analyze → Investigate → Respond**

---

### A.8.23 — Web Filtering

Organizations should control and filter users' access to websites.

Examples:

- URL filtering
    
- Malicious website blocking
    
- Category-based web filtering
    
- Blocking known phishing sites
    
- Blocking inappropriate or unauthorized websites
    

**Goal:** Reduce the risk of malware, phishing, malicious downloads, and inappropriate internet usage.

---

### A.8.28 — Secure Coding

Organizations should establish and apply **secure coding principles** throughout software development.

Examples:

- Input validation
    
- Secure authentication
    
- Proper error handling
    
- Secure session management
    
- Avoiding hard-coded credentials
    
- Secure handling of secrets
    
- Code review
    
- Security testing
    
- Vulnerability remediation
    

**Goal:** Prevent security vulnerabilities from being introduced into applications.

---

## A.8 in one line

> **A.8 protects technology and information through technical controls such as secure configuration, deletion, masking, DLP, monitoring, web filtering, encryption, access control, and secure software development.**
