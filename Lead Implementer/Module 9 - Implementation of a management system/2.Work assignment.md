
A **work assignment** is a task included in the project plan that contributes to the progress of the project.

A work assignment can be performed by:

- One person
    
- A group of people
    
- A project team
    

---

### 1. Prepare an Agenda

Before each work assignment, a good practice is to send an **agenda** to the participants.

The agenda should include:

- Start time
    
- Topics to be discussed
    
- Activities to be performed
    
- Expected outcomes
    
- End time
    

This helps participants prepare and keeps the assignment focused.

---

### 2. Follow Up Previous Assignments

If work was assigned during a previous meeting, the Project Manager should:

- Review the previous to-do list.
    
- Check the status of assigned tasks.
    
- Request required materials on time.
    
- Review submitted materials before the next assignment.
    
- Identify delayed activities.
    

This prevents unfinished work from accumulating.

---

### 3. Conduct the Work Assignment

During the assignment:

- Follow the agreed agenda.
    
- Focus on the planned activities.
    
- Discuss relevant issues.
    
- Make required decisions.
    
- Record important actions and outcomes.
    

Avoid unnecessary discussions that can delay the planned work.

---

### 4. Create a To-Do List

At the end of each work assignment, agree on a **to-do list** for the period until the next assignment.

Each task should clearly identify:

- **What** needs to be done.
    
- **Who** is responsible.
    
- **When** it must be completed.
    

### Example

|Task|Responsible|Deadline|
|---|---|---|
|Update Access Control Policy|ISMS Manager|15 Aug|
|Prepare employee training|HR Manager|18 Aug|
|Review performance records|CISO|20 Aug|

---

### 5. Follow Up the To-Do List

After the assignment, the Project Manager should:

- Complete their own assigned tasks.
    
- Remain available to help team members.
    
- Regularly check task status.
    
- Follow up on delayed activities.
    
- Remind team members about important deadlines.
    
- Ensure project activities remain a priority.
    

The Project Manager should make sure that team members understand the **importance of timely contributions**.

---

### 6. Common Work Assignment Tasks

Typical tasks may include:

- Developing new procedures.
    
- Creating new forms.
    
- Making layout or process changes.
    
- Implementing project activities.
    
- Reviewing performance records.
    
- Identifying trends.
    
- Preparing training events.
    
- Making decisions based on discussions.
    
- Updating project documentation.
    
- Reviewing previously assigned actions.
    

---

### 7. Simple Work Assignment Cycle

**Plan → Send Agenda → Perform Work → Assign Tasks → Set Deadlines → Follow Up → Review → Next Assignment**

### Key Point

> **A work assignment should always end with clear actions, responsible persons, and deadlines. Regular follow-up ensures that assigned work continues to move the project forward.**
