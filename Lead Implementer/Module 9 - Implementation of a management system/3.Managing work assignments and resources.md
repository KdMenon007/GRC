
During implementation, some project activities can be performed **in parallel** instead of sequentially. Parallel execution can reduce the overall project duration and help the organization achieve results faster.

### 1. When to Use Parallel Execution

Parallel work can be considered when:

- The organization has enough **competent team members**.
    
- Different departments can work on different assignments simultaneously.
    
- Required resources are available.
    
- The project manager has enough capacity to coordinate multiple activities.
    
- Parallel activities do not create dependencies or conflicts.
    

### Example

Different departments can work simultaneously on:

- HR → Security awareness and training
    
- IT → Access control implementation
    
- Facilities → Physical security controls
    
- Procurement → Supplier security requirements
    

This can shorten the overall implementation timeline.

---

## 2. Resource Availability

The **project manager** must ensure that the resources agreed upon for the project are actually available.

Resources may include:

- People
    
- Time
    
- Budget
    
- Technology
    
- Tools
    
- Expertise
    
- Management support
    

The project manager should continuously assess whether resources are sufficient for the planned activities.

---

## 3. Team Member Availability

Before assigning work, confirm that team members have enough time to participate.

Consider:

- Do team members have sufficient time for project tasks?
    
- Are responsible managers available for meetings?
    
- Can employees complete assigned activities within the required deadlines?
    
- Are competent people available for specialized activities?
    

A project can be delayed even when the plan is correct if the required people are not available.

---

## 4. Management Commitment

Management commitment is critical for successful implementation.

When management approves an investment or improvement, the project manager should verify that the decision is actually implemented.

Examples:

- Management approves security software → Is it actually purchased and deployed?
    
- Management approves security training → Is the training actually conducted?
    
- Management approves additional security resources → Are those resources actually provided?
    
- Management introduces a new security procedure → Are managers following and enforcing it?
    

### Management Must Lead by Example

Managers should:

- Follow the new procedures.
    
- Support project activities.
    
- Attend required meetings.
    
- Provide necessary resources.
    
- Encourage employees to follow the new practices.
    

---

## 5. Project Manager's Responsibility

The project manager should:

- Plan resource requirements.
    
- Ensure resources are available.
    
- Coordinate parallel assignments.
    
- Monitor team capacity.
    
- Identify obstacles to project progress.
    
- Communicate problems to responsible managers.
    
- Resolve resource-related issues.
    
- Escalate serious problems to the **project sponsor** when necessary.
    

---

## 6. Escalation

If a manager or department is preventing the project from progressing, the project manager should first attempt to resolve the issue directly.

If the issue cannot be resolved, it should be **escalated to the project sponsor**.

The project sponsor can help:

- Resolve conflicting priorities.
    
- Obtain additional resources.
    
- Resolve management-level conflicts.
    
- Remove organizational obstacles.
    
- Reinforce the importance of the project.
    

---

## 7. Risks of Parallel Assignments

Parallel execution can speed up the project, but it also increases the coordination workload.

Potential problems include:

- Too many activities being managed simultaneously.
    
- Communication gaps.
    
- Conflicting priorities.
    
- Resource shortages.
    
- Missed dependencies.
    
- Increased workload for the project manager.
    
- Reduced quality of project monitoring.
    

### Important Point

> **The project manager can become the bottleneck when too many work assignments are running simultaneously.**

Therefore, parallel execution should only be used when the project manager has enough capacity to coordinate and control the activities effectively.

---

## 8. Key Principle

The objective is **not simply to perform more activities at the same time**.

The objective is to:

> **Reduce project duration while maintaining proper coordination, quality, resource availability, and control.**

### Project Manager Checklist

Before running activities in parallel, check:

- ✅ Are competent people available?
    
- ✅ Are resources available?
    
- ✅ Do the activities have dependencies?
    
- ✅ Can departments work independently?
    
- ✅ Is management available?
    
- ✅ Can I coordinate all activities effectively?
    
- ✅ Are deadlines realistic?
    
- ✅ Is escalation support available if required?
    

**Main takeaway:** Parallel execution can accelerate an ISO 27001 implementation project, but it must be balanced against available resources and the project manager's ability to coordinate and control the work.
