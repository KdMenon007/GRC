
### 1. Project Sponsor

The **Project Sponsor** provides senior-level support but does not normally participate in the day-to-day implementation.

Responsibilities:

- Receive regular project status updates from the Project Manager.
    
- Provide management support when the project is delayed or blocked.
    
- Help obtain required resources.
    
- Resolve conflicting organizational priorities.
    
- Escalate and resolve major issues.
    
- Support the successful implementation of the management system.
    

**Key point:**  
The Project Sponsor provides **authority, resources, and management support**.

---

### 2. Project Manager

The **Project Manager** is responsible for coordinating and controlling the implementation project.

Responsibilities:

- Coordinate the overall project.
    
- Ensure required resources are available.
    
- Prepare and maintain the project plan.
    
- Define activities, responsibilities, and deadlines.
    
- Monitor project progress.
    
- Control project execution and quality.
    
- Communicate project status to the Project Sponsor.
    
- Coordinate the Project Team.
    
- Handle project administration.
    
- Identify and escalate problems.
    
- Ensure the project remains within the agreed timeline.
    

The Project Manager should have **sufficient authority** to keep the project moving and meet the established deadlines.

**Key point:**  
The Project Manager is responsible for **planning, coordinating, monitoring, and controlling the project**.

---

### 3. Project Team

The **Project Team** supports the Project Manager in implementing the management system.

Responsibilities:

- Perform assigned project activities.
    
- Provide expertise from different departments.
    
- Assist in developing policies, procedures, and other documentation.
    
- Participate in risk assessment and treatment activities.
    
- Help implement required processes and controls.
    
- Provide information and evidence required for the project.
    
- Make decisions requiring a **multidisciplinary approach**.
    
- Participate in project meetings and reviews.
    
- Review important project documents before finalization.
    

The Project Team should meet:

- Before the final version of important project documents is completed.
    
- Whenever the Project Manager considers a meeting necessary.
    
- When important decisions or project issues require team input.
    

---

### 4. Consultant

If the implementation is performed with an external consultant, the consultant can support the organization by:

- Providing ISO 27001 expertise.
    
- Guiding the organization through implementation.
    
- Helping identify gaps.
    
- Supporting risk assessment and treatment.
    
- Advising on required policies and procedures.
    
- Supporting implementation of controls.
    
- Providing templates and practical guidance.
    
- Helping prepare the organization for certification.
    

However, **responsibility for the ISMS ultimately remains with the organization**, not the consultant.

---

## 5. Roles and Responsibilities in the Project Plan

For a well-controlled implementation, the project plan should identify:

- Each project participant.
    
- Their role.
    
- Their responsibilities.
    
- Their authority.
    
- Required resources.
    
- Access to project information.
    
- Communication channels.
    
- Reporting responsibilities.
    

### Example

|Role|Main Responsibility|
|---|---|
|**Project Sponsor**|Management support, resources, escalation|
|**Project Manager**|Planning, coordination, monitoring, control|
|**Project Team**|Execute tasks and provide expertise|
|**CISO / ISMS Manager**|Information security leadership and ISMS coordination|
|**Department Owners**|Implement requirements within their departments|
|**Consultant**|Provide ISO 27001 guidance and implementation support|
|**Internal Auditor**|Independently assess ISMS conformity and effectiveness|

## 6. Communication Flow

Communication should be clearly defined so everyone knows:

- **Who needs information**
    
- **What information they need**
    
- **How much information they need**
    
- **How often they need it**
    
- **Who reports to whom**
    
- **How issues are escalated**
    

A typical communication flow is:

**Project Team → Project Manager → Project Sponsor / Top Management**

The Project Manager should regularly communicate:

- Current project status
    
- Completed activities
    
- Delayed activities
    
- Reasons for delays
    
- Problems encountered
    
- Unresolved issues
    
- Required management decisions
    
- Upcoming activities
    
- Resource requirements
    

---

## 7. Important Principle

> **The Project Sponsor provides authority and resources, the Project Manager controls the project, and the Project Team performs the implementation activities.**

Clear roles and responsibilities prevent confusion, duplication of work, delays, and conflicts during ISO 27001 implementation.
